**Learned**: The migration pattern requires two distinct steps: (1) scaffold fields on Editor with Default impls in 5.B.18, (2) update all call sites and remove App duplicates in 5.B.19. Perl batch replacements (`s/app\.pending_/app.editor.pending_/g`) efficiently handle ~300 call site updates across multiple files. Boot initializations for non-default fields (the 6 channels with production endpoints) must be moved into the `editor: Editor { ... }` constructor block in boot.rs.
