Prefer meeting-based information gathering over async written updates from department leads.

**Why:** Asking leads to write separate standup notes on top of standups they already run adds friction and extra work. The user will attend the standups directly and summarise key points themselves.

**How to apply:** When designing coordination rhythms for the Yamaha engagement (or similar client engagements), default to "attend the standup and summarise" rather than "ask leads to write async updates." The synthesis work sits with the engagement director, not the dept leads.
